# Contributing

Thanks for your interest in Awesome Odoo MCP. Contributions of new projects,
corrections, and better descriptions are welcome.

## Adding a project

1. Open a pull request against `main` that adds exactly one entry.
2. Put the entry in the section that fits best: External MCP Servers, Native
   Odoo Addons, or Hosted / Managed MCP Services.
3. Keep the existing table columns and fill in every cell. Use `—` when a
   column does not apply.
4. Link to the source repository and/or the Odoo App Store listing. Only
   primary sources, no URL shorteners or affiliate links.
5. Write a one-sentence description that says what makes the project
   different. Do not use marketing language.

## Guidelines

- The project must be about MCP and Odoo and must still be maintained.
- No dead links, duplicate links, or duplicate projects.
- A fork is only accepted when it adds a meaningful feature over the upstream
  project.
- Do not reorder or reformat unrelated entries in the same pull request.
- Descriptions end with a period and contain no emoji.

## Reporting a problem

If an entry is outdated, the project is gone, or a description is wrong, open
an issue or a pull request with the correction.
